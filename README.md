# Aranthia_Adventure_Game 
Aranthia Adventure Game is a text-based, fantasy choose your own adventure game! Role as the player is to defeat Vorgath who has taken over the world of Aranthia. It's your job to save Aranthia and get to the Aetherium Stone before Vorgath does. Your choices in this game will have consequences which will determine your fate in saving Aranthia!

## Technologies Used 

  - Python 3 (Main programming for development of code)
  - Python IDLE (Development environment and testing)
  - Python Standard Library (Built-in modules such as time and sys)
  - ANSI Escape Codes (Italicising text)
  - Github (Sharing and uploading project)
    
## Features

  - Branching storylines & 8 different endings
  - Player choices using conditional statements
  - Inventory system for collecting items
  - Functions for building storylines

## Usage

  - I recommend to download the Python file and open a terminal (as it uses ANSI escape codes) in its folder and run:
    - python 3 Aranthia Adventure Game.py
  - Follow the story prompts, you can answer choices such as with yes, no, 1 or 2
  - Click "Enter" to progress through the story
  - Collect items, make decisions and discover different endings!
